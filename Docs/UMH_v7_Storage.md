# UMH v7 存储与板载外设

## 外置 NOR Flash

HG25Q128M/TR 为 128 Mbit、16 MiB SPI3 NOR，仅保存低频对象，例如未来查找表或设备辅助数据。播放块、相位帧和波形绝不写入 Flash，因此设备不承诺超出 RAM 的离线循环；`LOOP_STREAM` 必须由主机继续供数。

SPI3 使用 8 bit 事务。底层驱动实现 JEDEC ID、状态寄存器、写使能、普通读取、DMA 快速读取、页编程、4 KiB 扇区擦除、64 KiB 块擦除、忙等待、超时、复位和总线恢复。页编程自动按页边界拆分，DMA 读取按固定缓冲分块。只有低优先级存储任务允许擦除或编程。

上层对象库把前 64 KiB 作为元数据日志，其余区域划分为两个擦除对齐的数据 bank。对象记录包含魔数、对象 ID、类型、版本、长度、地址、代数、CRC32 和提交标志。写入顺序是先写数据，再追加未提交元数据，最后单独写提交标志；挂载时只接受提交值正确、地址范围正确且数据 CRC 正确的最新记录。新版本追加写入，删除追加 tombstone；当前 bank 空间不足时，低优先级存储任务擦除备用 bank，将仍然有效的对象逐页复制过去，再追加新的地址记录并切换 bank。元数据耗尽后快照当前对象并轮换擦除元数据块。相同 ID、类型、版本、长度和 CRC 的对象跳过写入，减少 NOR 磨损。数据页写成功后即使元数据提交失败也会保留已消耗地址，避免后续对象覆盖孤儿数据。

## AT24C16 运行时参数

AT24C16 的 2 KiB 分为两个 1 KiB 副本区。记录包括魔数、结构版本、生成号、有效载荷长度、84 路相位校准、84 路增益修正、84 路使能位图、4 路 RGB 修正、数字默认参数、CRC32 和提交标志。启动时读取两个副本，选择 CRC 正确且 generation 最新者；两份均无效时加载编译默认值并报告校准无效。EEPROM 是运行时校准唯一权威来源，Flash 对象不能覆盖它。

提交过程为读取当前记录、合并待写字段、写入非活动副本、等待内部写周期、回读校验、写入提交标志并切换活动副本。所有读写按 AT24C16 的 16 字节页边界拆分，并在 I2C1 总线互斥锁内完成。器件地址的高位块选择由 2 KiB 地址编码，单次操作不能跨越 256 字节块边界。

## OLED 和按键

SSD1315 兼容 OLED 为 128x64，保留 1 KiB framebuffer 和 shadow buffer。驱动采用页寻址、脏页跟踪和 I2C DMA，只发送发生变化的页；OLED 与 AT24C16 共用 I2C1 互斥锁，DMA 缓冲为对象内部静态缓冲。显示内容限于连接、播放、FPGA、存储、校准、错误计数和资源额度等设备状态。

KEY0 至 KEY3 统一采样、三次稳定判定和约 30 ms 去抖，定义依次为 Return、Confirm、Down、UP。事件队列提供按下、释放、长按和组合事件；按键动作由设备 UI 状态机映射，不携带应用专用语义。

HEART 由健康任务以低优先级驱动心跳指示。LED1 至 LED4 保持电源、心跳和 CH347T 等硬件指示用途，不与四颗 WS2812C-2020-V6 的 RGB 数据模型混用。电源链路包含 DC 输入、SS-12D06G5、XL1509-5.0、AMS1117-3.3、肖特基二极管、磁珠和各级去耦；固件只负责安全初始化和输出关闭，不假设存在电压或温度 ADC。调试/JTAG 接口保持可用。

## RAM 约束

播放数据全部使用静态 RAM：USB 接收环约 16 KiB，响应池约 4 KiB，块描述和源记录约 20 至 24 KiB，帧环 32 个 400 字节槽并配有独立 LOOP_RAM 池，FPGA DMA 缓冲约 4 KiB，OLED 约 1 KiB，任务栈和控制对象约 12 至 16 KiB。USB、SPI 和 I2C DMA 缓冲独立放入 DMA 区域。禁止通用堆扩容播放池，编译期断言固定通道数、RGB 数量、麦克风数量、位图尺寸、帧尺寸和 profile wire size。

## 设计资料核对

84 路阵元坐标和 `E## -> Tn -> FPGA ball` 关系来自 `Reference/UMH 7 Element Layout`，固件按稳定阵元 ID 顺序装载并开启 `GEOMETRY_VALID`。坐标采用理论六角晶格的整数微米值，实际声学中心误差仍需加工后测量校准。生产资料中的 FPGA 料号和网表封装字符串仍需复核。所有状态、错误和资源额度都通过 `DeviceProfile`、`STATUS`、`FPGA_STATUS` 和 `ERROR_COUNTERS` 提供给主机。
